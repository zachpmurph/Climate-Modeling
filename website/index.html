What this is

Flood Explorer is the public window onto a set of open 1-D and 2-D river flood solvers (kinematic wave, 1-D Saint-Venant, 2-D Saint-Venant). The Playground runs JavaScript ports of the numerics live in your browser; the ports are held to the Python implementations by automated parity tests (tolerance ≤ 1e-8). Only ports that currently pass — kinematic wave and 2-D Saint-Venant — are offered; the 1-D Saint-Venant port trails a recent solver rewrite and is paused until it is re-synced, with the parity test tracking the gap. The Validation tab compares the Python 2-D solver with real gauge records.

A Regions tab — precomputed "what if" flood scenarios for specific reaches — has been set aside for now. Projecting named-place impacts is only worth showing once the model has earned that trust against observed data, and the Validation tab makes plain that it has not yet. It will return when the numbers support it.

How the solvers are checked

The 2-D solver is verified to a formal numerical standard (convergence studies, well-balancing, positivity, conservation); the 1-D solvers pass mass-balance and analytical-equilibrium tests. That is verification — the equations are solved correctly. Whether they describe a real river is validation, a separate question answered only by observed data.

What the Validation tab shows

That is where the question is put honestly: the Saint-Venant 2-D solver run against twelve real events on eight rivers — the Colorado below Glen Canyon Dam, the Truckee, the Rio Grande (a predeclared one-shot test), the Delaware, Connecticut, Potomac, Russian, and Snoqualmie — compared with what the downstream gauge recorded, every event 2-D with its declared terrain and nothing tuned to match. The results run the full range: near-perfect where the flow really moves (Potomac and Connecticut correlation 0.99), biased low on the regulated Colorado, and a genuine miss on the Russian (76% under). Two traps are handled openly — Nash–Sutcliffe becomes unreliable when a river barely varies, so every score is shown next to the event's variability; and each event carries a diagnosis (how much volume and how much of the swing the model delivered, how far off its routing time was) with a volume-only counterfactual whose oracle guard is printed alongside it. Results are reported as-is rather than tuned away.

What this is not

This is a screening and education tool, not a flood forecast. In the Playground, 1-D depths are cross-section averages — how high the water gets, not how far it spreads — and the 2-D model produces an inundation extent only over an idealised straight compound channel, a picture of how water behaves on that geometry rather than a map of any real floodplain, with no levees, buildings, bridges, culverts, or infiltration. Roughness and geometry are estimates, and where observed data has been compared the model shows real biases (see the Validation tab). Nothing here is calibrated. Do not use this site for safety-critical decisions.

Units

The models compute in meters and minutes (Manning n = SI value / 60, g = 35316 m/min²). The interface accepts familiar units (SI n, mm/h rain) and converts internally.
