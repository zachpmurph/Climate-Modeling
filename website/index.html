What this is

Flood Explorer is the public window onto a set of open 1-D and 2-D river flood solvers (kinematic wave, 1-D Saint-Venant, 2-D Saint-Venant) with a real-world data-ingestion pipeline. The Regions tab shows precomputed scenarios produced by the actual Python solvers over each region's channel profile or valley grid. The Playground runs JavaScript ports of the same numerics in your browser; all three ports are held to the Python implementations by automated parity tests (tolerance ≤ 1e-8).

Where the numbers come from

The Columbia — Hanford Reach profile is built by the repository's ingestion pipeline from DEM elevations, USGS gauge data, and reviewed channel roughness, with every value carrying provenance metadata. The other regions are clearly labeled synthetic reaches chosen to span contrasting flood behaviors. The 2-D solver is verified to a formal numerical standard (convergence studies, well-balancing, positivity, conservation); the 1-D solvers pass mass-balance and analytical-equilibrium tests.

Verified is not the same as validated

Verification asks whether the equations are being solved correctly, and this suite is verified to a formal standard. Validation asks whether those equations describe a real river — a separate question, answered only by observed data. The Validation tab is where that question is put honestly: the same solver run against real events on three rivers — the Colorado below Glen Canyon Dam, the Truckee at Reno, and a predeclared one-shot test on the Rio Grande — compared with what the downstream gauge recorded, with nothing tuned to match. Where the flow really moves the model does well (Truckee correlation 0.998); on the regulated Colorado it tracks shape but runs biased low; and the tab is careful about a trap — Nash–Sutcliffe becomes unreliable when a river barely varies, so every score is shown next to the event's variability. Where a calibrated fit is shown, its parameters' identifiability warning is shown with it, so calibrated is never read as validated. Results are reported as-is rather than tuned away.

What this is not

This is a screening and education tool, not a flood forecast. For the 1-D regions, depths are cross-section averages: they say how high the water gets, not how far it spreads. The 2-D region does produce an inundation extent, but over an idealised straight compound channel — it is a picture of how water behaves on that geometry, not a map of any real floodplain, and it contains no levees, buildings, bridges, culverts, or infiltration. Roughness and geometry are estimates; the models are verified numerically but, where observed data has been compared, show real biases (see the Validation tab). The scenarios shown here are uncalibrated. Do not use this site for safety-critical decisions.

Units

The models compute in meters and minutes (Manning n = SI value / 60, g = 35316 m/min²). The interface accepts familiar units (SI n, mm/h rain) and converts internally.
