What this is

Flood Explorer is the public window onto a set of open 1-D and 2-D river flood solvers (kinematic wave, Saint-Venant) with a real-world data-ingestion pipeline. The Regions tab shows precomputed scenarios produced by the actual Python solvers over each region's channel profile. The Playground runs JavaScript ports of the same numerics in your browser; the ports are held to the Python implementations by automated parity tests (tolerance ≤ 1e-8).

Where the numbers come from

The Columbia — Hanford Reach profile is built by the repository's ingestion pipeline from DEM elevations, USGS gauge data, and reviewed channel roughness, with every value carrying provenance metadata. The other regions are clearly labeled synthetic reaches chosen to span contrasting flood behaviors. The 2-D solver in the repository is verified to a formal numerical standard (convergence studies, well-balancing, positivity, conservation); the 1-D solvers used here pass mass-balance and analytical-equilibrium tests.

What this is not

This is a screening and education tool, not a flood forecast. Depths are cross-section averages from 1-D models; they do not define a 2-D inundation boundary. Roughness and geometry are estimates; the models are verified numerically but not calibrated against observed flood events. Do not use this site for safety-critical decisions.

Units

The models compute in meters and minutes (Manning n = SI value / 60, g = 35316 m/min²). The interface accepts familiar units (SI n, mm/h rain) and converts internally.
